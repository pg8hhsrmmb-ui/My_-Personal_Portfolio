Sarawak Heritage Auction Application

The Sarawak Heritage Auction Application is a web-based auction platform designed to support the trading of Sarawak heritage items. The project includes a database system and web interface for managing users, categories, auction items, bids, orders, and reports.

The report presents the database design, normalization, SQL implementation, and screenshots of the web application.
